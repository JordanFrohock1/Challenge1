## QUINNIPIAC'S OFF BRAND EBAY

# What is this project?
Quinnipiac wants to make their own version of EBAY so students can buy and sell items like furniture or books. How this benefits Quinnipiac, no one knows but 4 quinnipiac students with limited coding experience took on the challenge of making this application.

# How it works
Users log in with predefined account credentials and can navigate through the user interface to browser for items, keep an eye on items they are selling or put somethin up for sale. 

# How this interface was developed
This project was developed collaboratively using GitHub, with team members working asynchronously on different components such as login, buying, selling, and cart management. The goal of the project is to showcase both functional application design and effective team-based version control practices.
